# Сортировка пузырьком

Проходим по массиву несколько раз. На каждом проходе сравниваем соседние элементы: если левый больше правого — меняем местами. За один полный проход самый большой элемент "всплывает" (как пузырёк) в конец массива. Повторяем проходы, пока массив не отсортирован.

Сложность:

Время: O(n²) в худшем и среднем случае (два вложенных цикла) — самая частая вещь, которую спросят.
Память: O(1) — сортировка "на месте", без дополнительных структур.

```javascript
function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    // n - 1 - i во внутреннем цикле. После каждого прохода i последние i элементов уже точно на своих местах (самые большие всплыли в конец) — их незачем перепроверять снова, это небольшая оптимизация.
    for (let j = 0; j < n - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]; // swap через деструктуризацию
      }
    }
  }
  return arr;
}
```

Частый доп. вопрос: "а можно ли завершить раньше, если массив уже отсортирован?" — да, через флаг:

```javascript
function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    let swapped = false;
    for (let j = 0; j < n - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
        swapped = true;
      }
    }
    if (!swapped) break; // если за проход не было ни одной перестановки — массив уже отсортирован
  }
  return arr;
}
```
