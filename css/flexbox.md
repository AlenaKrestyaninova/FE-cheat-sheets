# Flexbox

### Что такое Flexbox

Flexbox (Flexible Box Layout) — это одномерная модель CSS-раскладки. «Одномерная» означает, что за один раз она работает либо со строками, либо со столбцами — в отличие от Grid, который двумерный. Flexbox решает задачи, которые раньше требовали костылей: вертикальное центрирование, равномерное распределение пространства между элементами, растягивание дочерних блоков по высоте родителя.

---

### Оси main и cross

Flexbox оперирует двумя осями:

 ![image.png](/users/a.kuzmina/css/flexbox/.files/image.png =542x228) 

**Main axis** — главная ось, вдоль которой выстраиваются flex-элементы. Направление задаётся свойством `flex-direction`: `row` (слева направо), `row-reverse`, `column` (сверху вниз), `column-reverse`.

**Cross axis** — поперечная ось, перпендикулярная главной. Если `flex-direction: row`, то cross axis идёт сверху вниз. Если `flex-direction: column`, то cross axis горизонтальная.

---

### justify-content и align-items

`justify-content` — распределяет элементы **вдоль главной оси**. Значения: `flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`.

`align-items` — выравнивает элементы **по поперечной оси** (для всех элементов в одной строке). Значения: `stretch` (по умолчанию), `flex-start`, `flex-end`, `center`, `baseline`.

---

### align-items vs align-content

**`align-items`** работает внутри одной строки/столбца — выравнивает элементы относительно друг друга в своём ряду.

**`align-content`** работает только когда есть несколько строк (при `flex-wrap: wrap`) — распределяет сами строки внутри контейнера по поперечной оси. Если строка одна, `align-content` не даёт эффекта.

---

### flex-grow, flex-shrink, flex-basis

**`flex-grow`** — коэффициент роста. Определяет, какую долю свободного пространства получит элемент. `flex-grow: 0` — не растёт (по умолчанию). `flex-grow: 1` у всех элементов — делят свободное место поровну. `flex-grow: 2` — получит вдвое больше свободного места, чем элемент с `flex-grow: 1`.

**`flex-shrink`** — коэффициент сжатия. Когда суммарный размер элементов превышает контейнер, браузер сжимает их. `flex-shrink: 1` — сжимается (по умолчанию). `flex-shrink: 0` — не сжимается никогда.

**`flex-basis`** — базовый размер элемента до распределения свободного пространства. Это как `width` (или `height` при `flex-direction: column`), но с учётом Flexbox-контекста. Значение `auto` означает «посмотри на `width`/`height`». Значение `0` означает «вся ширина — из `flex-grow`».

---

### Свойство flex (шорткат)

`flex` — сокращение для трёх свойств: `flex-grow flex-shrink flex-basis`.

---

### Центрирование элемента

css

```
.container {
  display: flex;
  justify-content: center; /* горизонталь */
  align-items: center;     /* вертикаль */
}
```

---

### Ограничения Flexbox

* Одномерный: для сложных сеток (строки \+ столбцы одновременно) нужен Grid.

* Нет привязки к сетке: элементы не выравниваются между разными строками.

* Сложные расчёты при `flex-grow/shrink` могут давать неожиданные размеры, особенно с `flex-basis: auto`.

* Не подходит для крупных лейаутов страницы — для этого Grid предпочтительнее.
