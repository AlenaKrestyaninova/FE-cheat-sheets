# Глобальные атрибуты

Это атрибуты HTML, которые можно использовать на **любом** HTML-элементе, независимо от его типа. Они определены в спецификации HTML и поддерживаются всеми тегами — от `<div>` до `<video>`.

### `id`

* Уникальный идентификатор элемента на странице. **Должен быть уникальным** в пределах документа.

* Используется для: навигации по якорям (`href="#section"`), обращения из JS (`getElementById`), стилизации в CSS (`#id`), связи `<label for="id">` с инпутом.

* Браузер не выдаёт ошибку при дублировании, но поведение становится непредсказуемым.

---

### `data-*`

* Позволяет хранить **произвольные данные** прямо в HTML-разметке без использования нестандартных атрибутов.

* Синтаксис: `data-` \+ любое имя в kebab-case: `data-user-id="42"`.

* В JS доступен через `element.dataset.userId` (автоматически преобразуется в camelCase).

* Не влияет на отображение, не виден пользователю, но виден в DevTools.

* Часто используется для передачи данных в обработчики событий, конфигурации компонентов.

---

### `hidden`

* Булев атрибут. Скрывает элемент — браузер применяет `display: none`.

* Элемент **не отображается** и **недоступен** для вспомогательных технологий (скринридеров).

* Отличие от `visibility: hidden` — элемент не занимает место в потоке.

* Важно: CSS может **переопределить** `hidden`, если явно задать `display: block`.

* В HTML5 также есть `hidden="until-found"` — элемент скрыт, но доступен для поиска по странице (Ctrl\+F).

---

### `tabindex`

* Управляет порядком фокуса при навигации с клавиатуры (Tab).

* `tabindex="0"` — элемент попадает в естественный порядок фокуса по DOM.

* `tabindex="-1"` — элемент исключён из Tab-навигации, но фокус можно поставить программно через `.focus()`.

* `tabindex="N"` (положительное) — задаёт явный порядок. Считается **антипаттерном**, усложняет поддержку.

* Важен для **доступности (a11y)**: интерактивные кастомные элементы (div-кнопки) без `tabindex` недоступны с клавиатуры.

---

### `contenteditable`

* Делает содержимое элемента **редактируемым** прямо в браузере.

* Значения: `true` / `false` / `""` (пустая строка = true) / `plaintext-only` (только текст, без HTML).

* Работает как мини-редактор: поддерживает вставку, форматирование, курсор.

* Содержимое **не сохраняется** автоматически — нужно обрабатывать через JS (событие `input`).

* Используется в WYSIWYG-редакторах, inline-редактировании в интерфейсах.
