# SEO для дебилов

### 1. Структура HTML-документа

```xml
<!-- Говорит браузеру: "Это современный HTML5, рендери по стандарту" -->
<!DOCTYPE html>
<html lang="ru">

<head>
  <!-- Всё что здесь — НЕ видно пользователю, Но очень важно для браузера и робота -->

  <meta charset="UTF-8"> <!-- Кодировка документа. UTF-8 поддерживает все языки мира. Без этого тега русский текст может превратиться в кракозябры  -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- тег говорит браузеру на телефоне: "Не сжимай страницу — она адаптивная". -->
  <title>Купить iPhone 15 — официальный магазин</title> <!-- это заголовок страницы. Он отображается в поисковой выдаче (кликабельная ссылка), во вкладке браузера -->
  <meta name="description" content="..."> <!--  -->
  <link rel="canonical" href="..."> <!--  -->

  <!-- Open Graph, микроразметка, шрифты — тоже сюда -->
</head>

<body>
  <!-- Всё что здесь — видно пользователю -->
</body>

</html>
```

### 2. Заголовки и семантическая структура `<body>`

**Один `<h1>` на страницу.** Он задаёт главную тему. Несколько `<h1>` — робот не понимает, что важнее.

**Не пропускай уровни.** После `<h2>` идёт `<h3>`, не `<h4>`.

**Заголовки — для структуры, не для стиля.** Если нужен крупный текст — используй CSS, не `<h2>` ради размера.

#### Главные семантические теги и их смысл

Семантика — это когда тег **описывает роль блока**, а не только его внешний вид.

`<header>` Шапка страницы или секции. Обычно содержит логотип, навигацию, заголовок.

`<nav>` Навигация. Говорит роботу: *"Здесь ссылки на другие разделы сайта"*. Если навигаций несколько — добавь `aria-label`.

`<main>` Главный контент страницы. **Один на страницу.** Всё, что уникально для этой страницы — внутри `<main>`. Шапка, подвал, боковые панели — снаружи.

`<article>`Самодостаточный контент — статья, пост, карточка товара, комментарий. Смысл: этот блок можно вырвать из контекста и он останется понятным.

`<section>` Тематический раздел страницы. Используй когда нужно сгруппировать контент по смыслу, и у раздела есть заголовок.

`<aside>`Второстепенный контент — боковая панель, реклама, похожие статьи. Робот понимает: это не главное.

`<footer>`Подвал страницы или секции. Копирайт, контакты, дополнительные ссылки.

`<time>`Дата и время. Атрибут `datetime` — машиночитаемый формат для робота. Google использует его чтобы понять свежесть контента.

### 3. Мета-теги

Description — это текст, который Google показывает под заголовком в поисковой выдаче. Называется **сниппет**.

```
<meta name="description" content="iPhone 15 Pro с чипом A17 Pro. Доставка за 2 часа. Цена от 99 990 ₽.">
```

**Правила:**

* до **160 символов** (дальше обрежется)

* уникальный для каждой страницы

* содержит ключевое слово естественно, не через запятую

* читается как живая фраза, желательно с призывом к действию

`<meta name="keywords">` - Google перестал учитывать этот тег в 2009 году

### 4. canonical

Если одна и та же страница часто доступна по нескольким URL - надо пометить оригинал. Это говорит роботу: *"Что бы ты ни читал — оригинал вот здесь. Индексируй его."*

```
<!-- На ВСЕХ дублях указываем на оригинал -->
<link rel="canonical" href="https://example.com/product/iphone-15"/>
```

### 5. Open Graph

— как страница выглядит в соцсетях

```xml
<head>
  <!-- Основные OG-теги -->
  <meta property="og:title" content="iPhone 15 Pro — купить в iStore"/>
  <meta property="og:description" content="Чип A17 Pro, камера 48 Мп. Доставка за 2 часа."/>
  <meta property="og:image" content="https://example.com/og/iphone15.jpg"/>
  <meta property="og:url" content="https://example.com/product/iphone-15"/>
  <meta property="og:type" content="product"/>
</head>
```

### 6. Микроразметка Schema.org

— добавляет машиночитаемый слой данных поверх HTML, который объясняет роботу смысл каждого значения. Делает сниппет внятным.

Формат микроразметки - JSON-LD

```
<head>
  ...
  <script type="application/ld+json">
  {
    "@context": "https://schema.org", // всегда https://schema.org. Говорит роботу: "используй словарь Schema.org"
    "@type": "Product", // тип объекта: Product, Article, Person, Organization и т.д.
    "name": "iPhone 15 Pro"
  }
  </script>
</head>
```
