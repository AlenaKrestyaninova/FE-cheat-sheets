# Версии HTML

### HTML 1.0–2.0 (начало 1990-х)

Самые первые версии, заложившие базу: заголовки, абзацы, списки, ссылки, простые формы. Ничего особенного — просто разметка текста.

### HTML 3.2 (1997)

Появились таблицы, возможность обтекания текстом изображений, некоторые визуальные элементы (например, `<font>` для управления шрифтами прямо в разметке).

### HTML 4.01 (1999)

Крупный шаг вперёд:

* Разделение на **Strict**, **Transitional** и **Frameset** — с явным отказом (в Strict) от визуальных тегов в пользу CSS

* Улучшенная поддержка таблиц, форм, скриптов

* Начало отделения содержания (HTML) от оформления (CSS)

### XHTML 1.0 (2000)

Не новая версия HTML как таковая, а переписывание HTML по строгим правилам XML: все теги нужно закрывать, атрибуты — в кавычках, теги — в нижнем регистре. Требовало более строгого синтаксиса, из-за чего многие сайты не соответствовали стандарту.

### HTML5 (черновик с 2008, финализация в 2014)

Самое значительное обновление:

* **Новые семантические теги**: `<header>`, `<footer>`, `<nav>`, `<article>`, `<section>`, `<aside>` — вместо кучи `<div>` с классами

* **Мультимедиа "из коробки"**: `<video>` и `<audio>` без Flash/плагинов

* **Графика**: `<canvas>` для рисования, поддержка SVG

* **Новые типы полей форм**: email, date, number, range и т.д. с встроенной валидацией

* **API для JavaScript**: геолокация, локальное хранилище (localStorage), Web Workers, drag-and-drop

* Отказ от строгого XML-синтаксиса — разметка стала более гибкой и снисходительной к ошибкам

### Сейчас — "HTML Living Standard"

Начиная с HTML5, стандарт перестал версионироваться в классическом смысле. Сейчас его развивает WHATWG как **"живой стандарт"** (Living Standard) — без номеров версий типа HTML6. Он постоянно и понемногу обновляется: добавляются новые элементы, атрибуты и API, а старое постепенно устаревает — без резких скачков, как раньше.
