# wiki-to-md

Конвертирует экспорт страницы Wiki Yandex ("сохранить как маркдаун" или `.html`-сохранение страницы) в чистый markdown.

Wiki Yandex — SPA: при обычном сохранении страницы браузером в `#root` попадает только html-заготовка загрузчика, а реальный текст статьи лежит в виде escaped-строки внутри встроенного JSON (`window.__DATA__`-подобный блок, поле `html`). Скрипт находит это поле, аккуратно разэкранирует его и прогоняет через [turndown](https://github.com/mixmark-io/turndown) с плагином таблиц.

## Использование

```
npm install
node wiki-to-md.js "путь/к/экспорту.html"
```

Имя выходного файла берётся из собственного slug страницы в Wiki (тот же, что в её ЧПУ-адресе) и сохраняется рядом с исходным файлом. Можно указать имя явно вторым аргументом:

```
node wiki-to-md.js "путь/к/экспорту.html" "путь/к/результату.md"
```

На выходе — файл с заголовком (взятым из поля `title` страницы) и markdown-содержимым: заголовки, списки, таблицы, код.

## Что стоит проверить после конвертации

- Опечатки и артефакты, которые были в исходном тексте — скрипт их не чинит.
- Изображения и вложения — они переносятся как ссылки на `yastatic.net`/внутренние адреса Wiki и не будут доступны извне, их нужно перекачать и вставить вручную.
- Внутренние ссылки на другие страницы Wiki — превратятся в markdown-ссылки на старые URL, их нужно поправить руками.
