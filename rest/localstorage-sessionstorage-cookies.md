# localStorage, sessionStorage, Cookies

## localStorage

**Особенности:**

* Данные хранятся бессрочно до явного удаления

* Синхронный API, может блокировать UI при больших операциях

* Хранится на диске, переживает перезагрузки и закрытие браузера

* Общий для всех вкладок одного домена

**Применение:** настройки пользователя, темы, языки, кэш данных, корзина покупок

```javascript
localStorage.setItem('key', 'value');
localStorage.getItem('key'); // 'value'
localStorage.removeItem('key');
localStorage.clear(); // очистить всё
```

## sessionStorage

**Особенности:**

* Изолирован для каждой вкладки

* Данные живут только пока открыта вкладка

* При дублировании вкладки данные копируются

* Тот же API, что у localStorage

**Применение:** временные формы, состояние многошагового процесса, данные для текущей сессии работы

## Cookies

**Особенности:**

* Автоматически включаются в HTTP-заголовки

* Можно читать/писать как в JS, так и на сервере

* Поддерживают множество атрибутов для безопасности

**Атрибуты:**

* `expires/max-age` — время жизни

* `domain/path` — область видимости

* `secure` — только по HTTPS

* `httpOnly` — недоступны из JS (только сервер)

* `sameSite` — защита от CSRF-атак

```javascript
document.cookie = "username=john; expires=Thu, 18 Dec 2025 12:00:00 UTC; path=/";
```

**Применение:** токены аутентификации, отслеживание сессий, настройки, которые нужны серверу

## Ограничения и нюансы

**Объем:** localStorage/sessionStorage \~5-10 МБ, cookies \~4 КБ на cookie 

**Приватность:** все очищаются в режиме инкогнито 

**Безопасность:** localStorage/sessionStorage уязвимы к XSS(*межсайтовый скриптинг)*, cookies можно защитить httpOnly 

**Производительность:** cookies увеличивают размер каждого HTTP-запроса
