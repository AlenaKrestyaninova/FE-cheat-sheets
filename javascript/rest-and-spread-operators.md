# Rest и spread операторы

### Spread — "разворачивает" (распаковывает)

Берёт итерируемую структуру (массив, объект, строку) и **разворачивает её элементы по отдельности**. Используется там, где ожидается несколько отдельных значений.

**В массивах:**

```javascript
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5]; // [1, 2, 3, 4, 5]

// копирование массива
const copy = [...arr1];

// объединение массивов
const merged = [...arr1, ...arr2];
```

**В объектах:**

```javascript
const obj1 = { a: 1, b: 2 };
const obj2 = { ...obj1, c: 3 }; // { a: 1, b: 2, c: 3 }

// частый паттерн — иммутабельное обновление state
const newState = { ...state, name: 'Новое имя' };
```

**В вызовах функций** — превращает массив в отдельные аргументы:

```javascript
function sum(a, b, c) {
  return a + b + c;
}

const nums = [1, 2, 3];
sum(...nums); // эквивалент sum(1, 2, 3)

Math.max(...[5, 1, 9]); // 9
```

### Rest — "собирает" (упаковывает)

Делает обратное: собирает **множество отдельных значений в один массив/объект**. Используется только в двух местах: параметры функций и деструктуризация.

**В параметрах функций** — собирает все "лишние" аргументы в массив:

```javascript
function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}

sum(1, 2, 3, 4); // numbers = [1, 2, 3, 4]
```

Важное правило: rest-параметр должен быть **последним** в списке параметров:

```javascript
function log(first, ...rest) {
  console.log(first); // первый аргумент отдельно
  console.log(rest);  // всё остальное — массивом
}

log(1, 2, 3, 4); // 1, [2, 3, 4]
```

**В деструктуризации массивов:**

```javascript
const [first, second, ...others] = [1, 2, 3, 4, 5];
// first = 1, second = 2, others = [3, 4, 5]
```

**В деструктуризации объектов:**

```javascript
const { id, ...rest } = { id: 1, name: 'Аня', age: 25 };
// id = 1, rest = { name: 'Аня', age: 25 }
```

Это, кстати, очень частый паттерн для "удаления" ключа из объекта иммутабельно:

```javascript
const { password, ...userWithoutPassword } = user;
```

**Мнемоника, которая часто помогает на собеседовании:** если `...` стоит **справа** от `=` или внутри вызова функции — это spread (мы "распаковываем" готовую структуру). Если `...` стоит **слева** от `=` (при деструктуризации) или в объявлении параметров функции — это rest (мы "собираем" значения).

js

```
const [a, ...rest] = arr;     // rest — слева, собирает
const newArr = [...arr, 4];   // spread — справа, разворачивает
```
