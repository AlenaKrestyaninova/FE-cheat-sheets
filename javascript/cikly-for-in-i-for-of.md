# Циклы for...in и for...of

### 1. **Цикл for...in**

Цикл for...in предназначен для перебора **собственных перечисляемых свойств** объекта (включая унаследованные, если они перечисляемые). Он перебирает **ключи** (имена свойств) объекта.

```javascript
const obj = { a: 1, b: 2, c: 3 };
for (let key in obj) {
  console.log(key, obj[key]); // a 1, b 2, c 3
}
```

**Особенности:**

* Перебирает **ключи** объекта (строки или символы).

* Подходит для объектов, а не для массивов (хотя технически работает с массивами, но это не рекомендуется).

* Может перебирать унаследованные свойства, если они перечисляемые (например, добавленные в прототип).

* Порядок перебора не гарантируется (хотя в современных движках обычно соответствует порядку определения свойств).

* Если объект имеет унаследованные свойства, они тоже будут перебраны, если не использовать hasOwnProperty:

### 2. **Цикл for...of**

Цикл for...of предназначен для перебора **значений** итерируемых объектов, таких как массивы, строки, Set, Map и другие объекты, реализующие протокол итерации (имеющие метод Symbol.iterator).

```javascript
const arr = [1, 2, 3];
for (let value of arr) {
  console.log(value); // 1, 2, 3
}

const str = "hello";
for (let char of str) {
  console.log(char); // h, e, l, l, o
}

const map = new Map([['a', 1], ['b', 2]]);
for (let [key, value] of map) {
  console.log(key, value); // a 1, b 2
}
```

**Особенности:**

* Перебирает **значения**, а не ключи.

* Работает с любыми итерируемыми объектами (массивы, строки, Set, Map, генераторы и т.д.).

* Не перебирает свойства объектов, так как обычные объекты не являются итерируемыми.

* Порядок перебора соответствует порядку элементов в итерируемом объекте.

* Не работает с обычными объектами, так как они не итерируемы. Для объектов можно использовать Object.keys(), Object.values() или Object.entries() с for...of:

### 3. **Классический цикл for**

Самый старый и универсальный способ. Подходит для массивов, когда нужен контроль над индексами.

```javascript
const arr = [1, 2, 3];
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]); // 1, 2, 3
}
```

**Когда использовать:**

* Когда нужен доступ к индексам или требуется сложная логика перебора (например, пропуск элементов, обратный порядок).

* Для оптимизации в редких случаях, где важна производительность.

### 4. **Метод forEach**

Метод массивов, принимающий функцию обратного вызова для каждого элемента.

```javascript
const arr = [1, 2, 3];
arr.forEach((value, index) => {
  console.log(value, index); // 1 0, 2 1, 3 2
});
```

**Когда использовать:**

* Когда нужна лаконичность и нет необходимости прерывать цикл (в отличие от for или for...of, forEach нельзя прервать с помощью break).

* Подходит для простых операций с элементами массива.

* Нельзя использовать break или continue. Для этого лучше использовать for...of.

### 5. **Методы map, filter, reduce и другие**

Эти методы массивов также используются для итерации, но с конкретными целями:

* map: создаёт новый массив, применяя функцию к каждому элементу.

* filter: создаёт новый массив с элементами, удовлетворяющими условию.

* reduce: сворачивает массив в одно значение.

```javascript
const arr = [1, 2, 3];
const doubled = arr.map(x => x * 2); // [2, 4, 6]
const evens = arr.filter(x => x % 2 === 0); // [2]
const sum = arr.reduce((acc, x) => acc + x, 0); // 6
```

**Когда использовать:**

* Когда нужно преобразовать массив или получить результат на основе его элементов.

### 6. **Итераторы и генераторы**

JavaScript поддерживает протокол итерации через Symbol.iterator и генераторы (функции с function\*).

**Пример с итератором:**

```
const arr = [1, 2, 3];
const iterator = arr[Symbol.iterator]();
console.log(iterator.next()); // { value: 1, done: false }
console.log(iterator.next()); // { value: 2, done: false }
console.log(iterator.next()); // { value: 3, done: false }
console.log(iterator.next()); // { done: true }
```

**Пример с генератором:**

```
function* generator() {
  yield 1;
  yield 2;
  yield 3;
}
for (let value of generator()) {
  console.log(value); // 1, 2, 3
}
```

**Когда использовать:**

* Для создания пользовательских итерируемых объектов или сложной логики перебора.
